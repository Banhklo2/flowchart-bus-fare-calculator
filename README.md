# 🚌 FlowChart Bus Fare Calculator

**FlowChart로 버스 요금 입력 검증 로직을 설계하고 Java로 구현한 연습**

---

## ✅ 시나리오: 버스 요금 입력 검증 시스템

- 사용자에게 버스 요금(price)을 입력받는다.
- 정상 요금 범위는 **0원 이상 3000원 이하**이다.
- 정상 범위를 벗어난 요금이 입력되면  
  → `"잘못된 요금입니다"`를 출력하고 다시 입력받는다.
- 정상 범위의 요금이 입력되면  
  → `"요금 확인 완료"`를 출력하고 프로그램을 종료한다.

## 📌 입력 / 출력 정리

### 입력(Input)
- 입력한 요금 `price`

### 출력(Output)
- 정상 범위일 경우: `"요금 확인 완료"`
- 비정상 범위일 경우: `"잘못된 요금입니다"`

### 상태(State)
- 없음 (누적 값 없이 입력 검증만 수행)

---

## 🔎 조건 정리

### 종료 조건
- 정상 범위의 요금이 입력된 경우

### 분기 조건
- `0 <= price <= 3000`

### 예외 / 에러 조건
- 요금이 음수인 경우
- 요금이 3000원을 초과한 경우

---

## 🔁 로직 흐름 설계

1. 시작 시
   - 요금을 입력받는다.

2. 반복
   1) 요금 `price`를 입력받는다.  
   2) 입력값이 `0 <= price <= 3000` 인지 확인한다.  
      - 예 → `"요금 확인 완료"` 출력 후 반복 종료  
      - 아니오 → `"잘못된 요금입니다"` 출력 후 다시 입력받기  

3. 종료 시
- 프로그램 종료
